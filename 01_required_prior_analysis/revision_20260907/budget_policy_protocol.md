# 예산별 정보수집 정책 분석계획

작성 시점: 신규 계산 실행 전. 연구 전체의 지위: 기존 평가자료를 이미 확인한 후향적 재분석. 사전등록이나 미사용 평가자료를 뜻하지 않는다.

- 자료: 기존 개발 2023→2024, 1,565명. 기존 평가 2024→2025, 1,520명. 기존 코드와 입력을 변경하지 않는다.
- 정보상황: history_available은 H 포함·제외 256개 조합과 P0를 허용한다. history_unavailable은 H 제외 128개 조합을 허용한다. 가용한 H의 실제 사용 여부는 선택결과이다.
- 추가 수집문항 예산: 모든 정수 0–30. H는 이미 보유했다면 추가비용 0. 나머지 블록 비용은 기존 원문항수이다. 문항수가 응답시간이나 법적 민감도를 측정하지 않는다.
- 학습계열: ridge, HGB. ridge C={.001,.01,.1,1,10}; HGB 기존 두 설정. 학습계열은 합치지 않고 각각 정책을 만든다.
- 선택: 예산 이하 후보 중 개발 OOF 로그손실 최소. 정확한 동률은 실제 추가문항수, 조합명의 오름차순. 허용손실 마진을 선택에 사용하지 않는다.
- 개발 전체 정책: 기존 동일 개발 OOF 예측/튜닝 결과를 검증 후 사용하고 P0의 동일 5개 폴드 OOF 예측을 직접 계산한다. 개발 함수는 평가파일을 읽지 않는다.
- 중첩 검증: 외부 층화 5겹×2반복, 각 외부 학습 안에서 내부 층화 5겹. 공통 분할을 모든 후보에 사용하고 전처리·튜닝·조합선택을 안쪽에서 수행한다. 예산별로 선택된 모델만 외부 폴드에 적합·평가한다.
- 중첩 성능: 반복별 참여자 OOF를 모아 손실을 계산한 후 두 반복의 평균을 보고한다. 두 반복을 독립 표본수의 증가로 취급하지 않는다. 폴드 선택빈도는 기술통계이다.
- 시간순 평가: 정책 동결 후 평가함수에서 기존 평가 예측 캐시와 입력·설정·ID 순서를 해시 및 재적합 예측으로 검증한다. 평가자료에서 좋은 예산을 개발선택으로 바꾸지 않는다.
- 공개 결과: 집계 CSV·설정·코드. 개인 ID·개인별 예측·원자료는 private 디렉터리에 보관하고 공개 배포에서 제외한다.
- 변경통제: 출력 생성 중 결과에 유리한 방향으로 예산·선택규칙·분할 수를 바꾸지 않는다. 큰 예산의 성능악화와 기준선 미달을 그대로 보고한다.
