# 후향적 정밀도 진단 및 주변 신뢰구간 추가 계획

작성 시점: 2026-09-08. 기존 2026-09-07 예산정책·정보블록 귀속 결과를 확인한 후 추가한 탐색적 분석이다. 사전등록·미사용 평가자료·새로운 확증분석을 뜻하지 않는다. 이 문서를 작성한 후 계산을 실행한다.

## 평가대상과 재사용 범위

- 개발자료에서 이미 확정한 124개 예산정책을 변경하지 않는다. 전체 평가 1,520명과 개인 비중복 평가 879명, 전체정보 및 기준선 대비 496개 행을 제시한다. 행 수와 서로 다른 대비 수는 다르다.
- 정책 대비는 기존 분석과 동일하게 학습기 2종 × 이력 가용성 2종 × 평가집단 2종의 8개 비교집합으로 나뉜다. 각 집합은 31개 예산정책의 전체정보·기준선 대비 중 중복 및 자기대비를 제거한 서로 다른 대비로 구성된다. 56개 블록 귀속은 별도의 단일 양측 비교집합이다.
- 정책은 난수시드 20260909, 블록 귀속은 2026090717의 기존 2,000회 개인 단위 짝지은 부트스트랩을 동일하게 재사용한다. 전체표본 가중치를 개인 비중복 집단에서 제한·재정규화한 기존 절차를 따른다.
- 개인 식별자는 문자열로 읽고 출력물에는 개인 자료·예측확률을 저장하지 않는다. 재학습·조합 선택·추가 모델 적합을 수행하지 않는다.

## 부호·주변구간·정밀도

정책 대비 d = 평균손실(정책) − 평균손실(참조)로 정의한다. 이득 g = −d가 양수이면 정책이 우수하다. 기존 주 분석의 단측 상한은 d + q_abs이며, 표준화 민감도 상한은 d + q_std·SE이다. 자기대비는 정확히 0이고 검출가능차이를 적용하지 않는다.

각 대비의 중심 부트스트랩 오차 e* = d_hat − d*로부터 기본 부트스트랩 주변 양측 95% 구간 [d_hat+Q.025(e*), d_hat+Q.975(e*)] 및 주변 단측 95% 상한 d_hat+Q.95(e*)를 계산한다. 공동구간과 주변구간을 모두 제공하고 후자를 다중 비교를 통제한 확증 결과로 사용하지 않는다. 주변구간은 이번 수정에서 추가되었으므로 사전지정으로 기술하지 않는다.

정규 국소 이동 근사하에서 양의 이득에 대한 80% 검출 규모를 MDD80 ≈ c + z.80·SE로 계산한다. c는 주 공동구간에서 q_abs, 표준화 공동구간에서 q_std·SE, 단측 주변 정규근사에서 z.95·SE이다. 이때 임계값과 오차분포는 현재 적합모형의 조건부 분포에 고정되어 있으며, 효과의 상수 이동에 따라 바뀌지 않는다는 가정을 둔다. 보조적으로 동일 부트스트랩 오차의 80백분위수에 기초한 국소 이동값 c+Q.80(d*−d_hat)을 계산한다. 이는 실제 연구의 달성 검출력, 정확한 전향적 최소검출효과, 다음 연구의 표본크기 추정, 적응적 재사용 보정이 아니다.

블록 귀속은 손실 감소 phi가 양수이면 이득이다. 기존 양측 56개 효과 공동구간의 양의 방향 하한이 0을 초과하는 사건에 대한 MDD80 근사를 계산한다. 이때 c=q_abs 또는 q_std·SE이고 근사는 c+z.80·SE이다. 주변구간의 양의 방향 발견은 양측 구간 하한을 사용하므로 z.975를 사용한다. 이는 양·음 어느 방향이든 발견하는 양측 검정의 전체 검출력을 산출한 값과 다르다. 부트스트랩 국소 이동은 c−Q.20(phi*−phi_hat)로 계산한다.

## 검증 및 보고

기존 248개 정책 행의 효과와 주·표준화 상한, 56개 귀속의 평균·표준오차·공동구간을 1e−10 이내로 재현한다. 주변구간의 자기대비·부호 변환·행 수·모든 예산 보존을 점검한다. 예산 1, 4, 11, 30의 기준선 대비 정밀도와 가상 이득 0.005 및 0.01의 크기를 비교하되, 모든 조건에서 불가능하다는 단정은 자료가 지지할 때에만 한다.

기존 372개 예산·집단 성능행의 Log loss, ROC-AUC, Average Precision, Brier 점수를 독립 산식으로 검산한다. 보정 기울기는 기존 수치를 같은 정의로 확인하고 무벌점 이항 로짓 우도 최적화로 수치 차이를 진단한다. 상수 예측의 기울기는 식별되지 않으므로 미정으로 유지한다. 본문 보조표용 예산 0, 1, 4, 11, 30의 표를 별도 산출한다.
