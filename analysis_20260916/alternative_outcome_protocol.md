# 대체 결과변수 코딩의 사후 민감도 분석

작성 시점: 2026-09-16. 이 문서는 본 민감도 분석의 첫 모형 적합 전에 작성한다. 원 연구와 이번 자료 점검에서 2025년 결과를 이미 확인했으므로 사전등록 또는 독립 검증으로 기술하지 않는다.

## 고정 사양

- 동일 참여자: 개발 2023→2024년 1,565명, 시간순 평가 2024→2025년 1,520명. 평가집단은 전체와 개발 참여자와 비중복인 879명이다.
- 결과변수만 변경: 월 1회 이상은 원 응답코드 1·2·3, 주 1회 이상은 원 응답코드 1·2를 양성으로 정의한다. 기존 `outcome_monthly_use`, `outcome_regular_use` 열을 사용하고 `outcome_frequency`로 다시 검증한다.
- 기존 모든 설명변수와 결측치 처리 및 블록을 유지한다. H는 기존의 `prior_any_use`로 고정한다. 결과변수의 임계값 변경과 이용이력 재정의를 혼합하지 않는다.
- 각 결과변수에서 256개 블록조합을 모두 비교한다. 릿지는 C={0.001,0.01,0.1,1,10}, HGB는 잎 수={3,7}, 학습률=0.05 등 기존 고정 사양을 그대로 사용한다.
- 각 결과변수별 층화 5겹 교차검증(시드 20260907)을 새로 생성한다. 모든 조합과 초모수에서 동일한 해당 결과변수별 분할을 사용한다. 전처리는 각 학습 폴드에서만 적합한다.
- 이용이력 가용 시 256개 조합과 P0를 허용하고, 미가용 시 H가 없는 128개 조합(NONE 포함)을 허용한다. 신규수집 예산은 0~30개 원문항이다. 선택은 개발 OOF 로그손실 최소값, 동률이면 실제 신규 문항 수, 조합명 사전순이다.
- P0는 각 결과변수에 대해 개발자료의 기존 H별 라플라스 평활 확률이며, NONE은 해당 개발 결과변수의 라플라스 평활 기저율이다.
- 결과변수별 조합·초모수·예산별 정책을 개발자료만으로 확정하고 해시 기록 후 평가한다. 평가 성능으로 정책을 다시 선택하지 않는다.
- 기존 반복 중첩 교차검증 전체를 반복하지 않는다. 본 분석의 OOF는 선택에 사용한 개발 OOF이며 중첩 교차검증의 비편향 성능 추정으로 해석하지 않는다.

## 평가 및 추론

- 개발자료 전체에 재적합한 고정 모형으로 전체 1,520명과 비중복 879명을 평가한다. 로그손실, ROC AUC, 평균정밀도(AP), Brier 점수, 보정절편·보정기울기를 계산한다. 상수 예측의 보정기울기는 정의하지 않는다.
- 보정모형은 기존 코드와 동일하게 로짓 예측값에 절편을 포함하는 로지스틱 회귀(C=1e8)를 사용한다. 추가 보정이나 재훈련에 평가자료를 사용하지 않는다.
- 전체 참여자에 대해 다항 부트스트랩 2,000회(시드 20260909)를 생성한다. 동일 배수를 비중복 하위집단에 제한한 뒤 합이 1이 되도록 정규화한다.
- 각 결과변수×예측모형×이용이력 가용성×평가집단을 독립된 보고 비교집합으로 둔다. 31개 정책과 전체정보 모형·기준모형 간 고유 비자기 대비를 중복 제거한다. 손실차의 기본 부트스트랩 오차 최대값의 95분위수를 공동 임계값으로 사용한다. 자기비교의 손실차와 상한은 0이다.
- 공동상한은 해당 비교집합 내 고정 예측에 대한 조건부 추론이다. 결과변수와 모형 및 평가집단 사이의 통합 다중비교 보장이나 선택·재적합 불확실성을 반영하지 않는다.
- 대표 예산은 결과 확인 전 0·1·4·11·30문항으로 정한다. 전체 31개 예산도 기계판독 파일로 제공한다. 부정적·비유의 결과도 모두 보고한다.

## 해석의 범위

대체 이진화는 응답 임계값에 대한 결론의 민감도를 점검한다. 2025년 지시문의 ‘자주’ 추가 및 서비스 예시 확대가 만든 측정변화를 제거하거나 시간 변화와 인과적으로 분리하지 않는다. 상이한 양성률에서 AP·Brier 및 로그손실의 절대값을 직접 우열로 해석하지 않는다.

## 재현 및 자료관리

원자료·개인별 파생자료·식별자·개인 예측값·폴드 할당은 private 폴더에만 저장하며 배포하지 않는다. 실행 코드, 사양, 자료 해시, 실제 패키지 버전, 개발 선택 결과, 집계 성능 및 추론 결과만 공개 산출물로 둔다. 모든 후보의 교차검증은 재개 가능한 체크포인트로 저장한다.
